# Personal preferences

## Environment
- Ubuntu laptop (also macOS at times). Shell: zsh with Oh My Zsh; node via nvm.
- Tools: emacs (`emacsclient -t` is the git editor), tmux, alacritty, JetBrains Mono.
- Repos live under `~/dev/src/github.com/<owner>/<repo>`.
- Dotfiles are symlinked from `~/dev/src/github.com/dotconfigfiles`: editing `~/.zshrc`, `~/.tmux.conf`, `~/.claude/settings.json` etc. edits that repo. Run `dotsync` to commit and push them.

## Working style
- Ask before anything hard to reverse or outward-facing (push, delete, overwrite).
- Look at the target before deleting or overwriting; prefer moving aside to a `.bak` file.
- Be concise: give a recommendation, not a survey of options.
- Default branch is `main`.
